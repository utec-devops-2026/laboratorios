## 🧰 Paso 0: Levantar MLflow (antes de abrir el notebook)

Tanto el notebook como el script registran parámetros, métricas y modelos en un **servidor de MLflow**. Si no está arriba, `mlflow.start_run()` falla con `ConnectionRefusedError`.

### `deployment/mlflow/docker-compose.yaml`

```yaml
services:
  mlflow:
    # Misma versión que el cliente del lab (pip mlflow==2.22.1): UI clásica de runs,
    # sin el modo GenAI/traces que abre por defecto MLflow 3.x.
    image: ghcr.io/mlflow/mlflow:v2.22.1
    container_name: mlflow-tracking-server
    ports:
      - "5555:5000"
    command: >
      mlflow server
      --host 0.0.0.0
      --port 5000
      --backend-store-uri sqlite:////mlflow/mlflow.db
      --artifacts-destination /mlflow/artifacts
    volumes:
      # Persistencia: runs (sqlite) y modelos logueados sobreviven a `docker compose down`.
      - mlflow-data:/mlflow

volumes:
  mlflow-data:
```

Tres decisiones de este archivo y su porqué:

| Decisión | Por qué |
| --- | --- |
| `image: ghcr.io/mlflow/mlflow:v2.22.1` (no `latest`) | Misma versión que el cliente del lab (`pip install mlflow==2.22.1`). `latest` hoy es MLflow 3.x: abre en modo **GenAI/traces** y los runs "no aparecen". |
| Volumen `mlflow-data:/mlflow` | Sin volumen, `mlflow.db` vive dentro del contenedor y **se pierde** con `docker compose down` o al cambiar de imagen. |
| `--artifacts-destination /mlflow/artifacts` | Los modelos logueados se guardan en el servidor, no en `/tmp/mlruns` de cada laptop. |

## 🎯 Paso 3: De Experimentación a Pipeline de Entrenamiento

### 📚 **¿Qué recibe el MLOps Engineer?**

El científico de datos entrega `notebooks/03_experimentation.ipynb`. Cada celda documenta **por qué** se tomó cada decisión (los comentarios están en el notebook):

| Celda | Qué hace | Decisión y porqué |
| --- | --- | --- |
| 1 · Imports y config | Librerías, logging, `mlflow_tracking_uri` | Métricas de **regresión** (`price` es numérico). Familias: lineal (baseline) + árboles/ensambles (tabular). |
| 1b · ¿Está MLflow? | `GET /health` al servidor | Fallar **antes** de entrenar (GridSearch tarda minutos). Si no responde, pone `mlflow_tracking_uri = None` y el notebook sigue sin tracking. |
| 2 · Carga y split | Lee `featured_house_data.csv`, usa la columna `split` | **No** se vuelve a hacer `train_test_split`: engineer.py ya separó train/test antes de ajustar el preprocessor. Re-partir mezclaría filas → leakage y un holdout distinto al de `train_model.py`. |
| 3 · RFE | `RFE(RandomForestRegressor, n_features_to_select=10)` | RFE evalúa features **en conjunto** (la correlación las mira una a una y solo lineal). RandomForest expone `feature_importances_`, no necesita escalar y no agrega dependencias. 10 es un hiperparámetro de diseño. |
| 4 · MLflow experiment | `set_experiment("House Price Prediction Experiment")` | Agrupar runs del mismo problema; manejar experimentos soft-deleted. |
| 5 · Modelos y grillas | LinearRegression, RandomForest, GradientBoosting, HistGradientBoosting | Escalera de complejidad: baseline → bagging → boosting → boosting por histogramas. NN/SVR fuera: más costo, no suelen ganar en tablas pequeñas. |
| 6 · Función de evaluación | `GridSearchCV(cv=3, scoring='r2')` + métricas en test | Mismo procedimiento para todos = comparación justa. `cv=3` por costo. `scoring='r2'` coherente con el criterio de selección final. |
| 7 · Loop del experimento | Run padre `model_comparison` + run hijo por modelo (`nested=True`) | Params, métricas y artefacto por modelo, comparables lado a lado en la UI. |
| 8 · Gráficos | Barras de R², RMSE, MAE | Ver si la diferencia es grande o marginal; si empatan, elegir el más barato de servir. |
| 9 · YAML | `configs/model_config.yaml` | Contrato entre experimentación y entrenamiento: ganador, hiperparámetros, métricas de referencia, features de RFE. |

### ⚡ **Transformación a Script de Producción**

El MLOps Engineer convierte esto en `src/models/train_model.py`. El bloque de abajo es el **archivo completo y vigente** del repositorio (incluye el *quality gate* del laboratorio 13.2): se puede copiar tal cual.

```python
# 🔧 Script de Producción del MLOps Engineer
import argparse
import pandas as pd
import numpy as np
import joblib
import sys
import mlflow
import mlflow.sklearn
from sklearn.model_selection import train_test_split
from sklearn.metrics import mean_absolute_error, mean_absolute_percentage_error, r2_score
from sklearn.dummy import DummyRegressor
from sklearn.ensemble import RandomForestRegressor, GradientBoostingRegressor, HistGradientBoostingRegressor
from sklearn.linear_model import LinearRegression
import yaml
import logging
from mlflow.tracking import MlflowClient

# Configuración de logging profesional
logging.basicConfig(
    level=logging.INFO,
    format='%(asctime)s - %(levelname)s - %(message)s'
)
logger = logging.getLogger(__name__)

def parse_args():
    """Argumentos de línea de comandos configurables."""
    parser = argparse.ArgumentParser(description="Train and register final model from config.")
    parser.add_argument("--config", type=str, required=True, help="Path to model_config.yaml")
    parser.add_argument("--data", type=str, required=True, help="Path to processed CSV dataset")
    parser.add_argument("--models-dir", type=str, required=True, help="Directory to save trained model")
    parser.add_argument("--mlflow-tracking-uri", type=str, default=None, help="MLflow tracking URI")
    return parser.parse_args()

def get_model_instance(name, params):
    """Factory para instanciar modelos desde configuración."""
    model_map = {
        'LinearRegression': LinearRegression,
        'RandomForest': RandomForestRegressor,
        'GradientBoosting': GradientBoostingRegressor,
        'HistGradientBoosting': HistGradientBoostingRegressor,
    }
    if name not in model_map:
        raise ValueError(f"Unsupported model: {name}")
    return model_map[name](**params)

def load_and_split_data(data_path, config):
    """Carga y divide datos usando configuración."""
    logger.info(f"Loading data from {data_path}")
    data = pd.read_csv(data_path)

    target = config['model']['target_variable']

    # Holdout fijo: se usa la columna `split` creada en feature engineering (guía 2).
    # No se vuelve a dividir aquí: así todos los modelos se evalúan sobre las mismas 16 casas
    # y el preprocessor nunca vio el test.
    train = data[data['split'] == 'train']
    test = data[data['split'] == 'test']

    features = [c for c in data.columns if c not in (target, 'split')]
    logger.info(f"Using {len(features)} features")

    X_train, y_train = train[features], train[target]
    X_test, y_test = test[features], test[target]

    logger.info(f"Data split: Train {X_train.shape}, Test {X_test.shape}")
    return X_train, X_test, y_train, y_test

def train_and_evaluate_model(model, X_train, y_train, X_test, y_test):
    """Entrena y evalúa el modelo."""
    logger.info("Training model...")
    model.fit(X_train, y_train)

    # Predicciones y métricas
    y_pred = model.predict(X_test)
    mae = mean_absolute_error(y_test, y_pred)
    r2 = r2_score(y_test, y_pred)
    rmse = np.sqrt(np.mean((y_test - y_pred) ** 2))
    mape = mean_absolute_percentage_error(y_test, y_pred)   # error relativo: 0.05 = 5 %

    # Baseline: predecir siempre la mediana de train. Un modelo que no le gana no sirve,
    # por muy bueno que parezca el R².
    baseline = DummyRegressor(strategy="median").fit(X_train, y_train)
    baseline_mae = mean_absolute_error(y_test, baseline.predict(X_test))

    metrics = {
        'mae': float(mae),
        'r2': float(r2),
        'rmse': float(rmse),
        'mape': float(mape),
        'baseline_mae': float(baseline_mae),
    }

    logger.info(f"Model performance - R²: {r2:.4f}, MAE: {mae:.2f}, RMSE: {rmse:.2f}, "
                f"MAPE: {mape:.4f} (baseline MAE {baseline_mae:.2f})")
    return model, metrics

def check_quality_gate(metrics, config):
    """Compara las métricas del holdout contra `model.quality_gate` del YAML.

    Devuelve la lista de incumplimientos (vacía = pasa). Umbrales opcionales:
      min_r2:             R² mínimo en el holdout
      max_mape:           error porcentual máximo
      must_beat_baseline: MAE debe ser menor que predecir la mediana
    """
    gate = config['model'].get('quality_gate', {}) or {}
    failures = []
    if 'min_r2' in gate and metrics['r2'] < gate['min_r2']:
        failures.append(f"R² {metrics['r2']:.4f} < min_r2 {gate['min_r2']}")
    if 'max_mape' in gate and metrics['mape'] > gate['max_mape']:
        failures.append(f"MAPE {metrics['mape']:.4f} > max_mape {gate['max_mape']}")
    if gate.get('must_beat_baseline', False) and metrics['mae'] >= metrics['baseline_mae']:
        failures.append(f"MAE {metrics['mae']:.0f} no mejora el baseline (mediana) {metrics['baseline_mae']:.0f}")
    return failures

def log_failed_gate(config, metrics, failures, mlflow_tracking_uri):
    """Deja constancia en MLflow del intento rechazado (sin registrar el modelo)."""
    if not mlflow_tracking_uri:
        return
    mlflow.set_tracking_uri(mlflow_tracking_uri)
    mlflow.set_experiment("House Price Prediction - Production")
    with mlflow.start_run(run_name="quality_gate_failed"):
        mlflow.log_params(config['model']['parameters'])
        mlflow.log_metrics(metrics)
        mlflow.set_tag("quality_gate", "failed")
        mlflow.set_tag("quality_gate_failures", " | ".join(failures))

def save_model_artifacts(model, config, metrics, models_dir):
    """Guarda modelo y artefactos."""
    import os
    os.makedirs(models_dir, exist_ok=True)

    # Guardar modelo entrenado
    model_path = os.path.join(models_dir, 'trained/house_price_model.pkl')
    os.makedirs(os.path.dirname(model_path), exist_ok=True)
    joblib.dump(model, model_path)

    # Actualizar configuración con métricas finales
    config['model']['final_metrics'] = {
        'mae': float(metrics['mae']),
        'r2': float(metrics['r2']),
        'rmse': float(metrics['rmse'])
    }

    # Guardar configuración actualizada
    config_path = os.path.join(models_dir, 'trained/house_price_model.yaml')
    with open(config_path, 'w') as f:
        yaml.dump(config, f)

    logger.info(f"✅ Model saved to {model_path}")
    logger.info(f"✅ Config saved to {config_path}")

    return model_path, config_path

def register_model_in_mlflow(model, config, metrics, mlflow_tracking_uri, X_sample=None):
    """Registra modelo en MLflow con metadatos completos.

    X_sample: DataFrame con algunas filas de entrada reales. Se usa para inferir la
    firma del modelo (nombres y tipos de columnas) y guardar un input_example:
    así MLflow valida en inferencia que lleguen las mismas features.
    """
    if not mlflow_tracking_uri:
        logger.info("No MLflow tracking URI provided, skipping MLflow logging")
        return None

    mlflow.set_tracking_uri(mlflow_tracking_uri)
    mlflow.set_experiment("House Price Prediction - Production")

    model_name = config['model']['name']

    with mlflow.start_run(run_name="production_training"):
        # Log parámetros del modelo
        mlflow.log_params(config['model']['parameters'])

        # Log métricas de rendimiento
        mlflow.log_metrics(metrics)

        # Log información adicional
        mlflow.log_param("total_features",
                        config['model']['feature_sets']['total_features'])
        mlflow.log_param("holdout", "split fijo 80/20 (random_state=42) de feature engineering")
        gate = config['model'].get('quality_gate', {}) or {}
        for k, v in gate.items():
            mlflow.log_param(f"gate_{k}", v)
        mlflow.set_tag("quality_gate", "passed")   # si llegó aquí, pasó el gate de main()

        # Registrar modelo con firma inferida de datos reales.
        # infer_signature(None, None) no es válido: necesita al menos inputs u outputs.
        signature, input_example = None, None
        if X_sample is not None and len(X_sample) > 0:
            input_example = X_sample.head(5)
            signature = mlflow.models.infer_signature(input_example, model.predict(input_example))

        mlflow.sklearn.log_model(
            sk_model=model,
            artifact_path="model",
            registered_model_name=model_name,
            signature=signature,
            input_example=input_example,
        )

        # Transicionar a producción: el umbral es el mismo min_r2 del quality gate
        # (default 0.8 si el YAML no define gate)
        min_r2 = (config['model'].get('quality_gate') or {}).get('min_r2', 0.8)
        if metrics['r2'] >= min_r2:
            client = MlflowClient()
            model_version = client.get_latest_versions(model_name, stages=["None"])[0]
            client.transition_model_version_stage(
                name=model_name,
                version=model_version.version,
                stage="Production"
            )
            logger.info(f"✅ Model promoted to Production stage in MLflow")

        run_id = mlflow.active_run().info.run_id
        logger.info(f"✅ Model logged to MLflow with run_id: {run_id}")
        return run_id

def main():
    """Pipeline principal de entrenamiento."""
    args = parse_args()

    # Cargar configuración del modelo
    logger.info(f"Loading config from {args.config}")
    with open(args.config, 'r') as f:
        config = yaml.safe_load(f)

    # Cargar y preparar datos
    X_train, X_test, y_train, y_test = load_and_split_data(args.data, config)

    # Instanciar modelo desde configuración
    model_name = config['model']['best_model']
    model_params = config['model']['parameters']
    model = get_model_instance(model_name, model_params)
    logger.info(f"Created {model_name} model with parameters: {model_params}")

    # Entrenar y evaluar
    trained_model, metrics = train_and_evaluate_model(
        model, X_train, y_train, X_test, y_test
    )

    # Quality gate (reto lab 13.2): si el modelo no cumple los umbrales del YAML,
    # NO se guarda ni se registra; el proceso termina con exit 1, el job de CI falla
    # y build-and-publish no corre.
    failures = check_quality_gate(metrics, config)
    if failures:
        for f in failures:
            logger.error(f"❌ Quality gate: {f}")
        log_failed_gate(config, metrics, failures, args.mlflow_tracking_uri)
        logger.error("Model NOT saved or registered. Exiting with code 1.")
        sys.exit(1)
    gate = config['model'].get('quality_gate') or {}
    logger.info(f"✅ Quality gate passed ({gate if gate else 'no thresholds defined'})")

    # Guardar artefactos localmente
    model_path, config_path = save_model_artifacts(
        trained_model, config, metrics, args.models_dir
    )

    # Registrar en MLflow
    run_id = register_model_in_mlflow(
        trained_model, config, metrics, args.mlflow_tracking_uri, X_sample=X_test
    )

    logger.info("🚀 Training pipeline completed successfully!")

    return {
        'model_path': model_path,
        'config_path': config_path,
        'metrics': metrics,
        'mlflow_run_id': run_id
    }

if __name__ == "__main__":
    main()
```

## 🔑 **Diferencias Clave: Notebook vs Script de Entrenamiento**

### 📓 **Código del Data Scientist (Notebook)**

- ✅ Experimentación interactiva con múltiples modelos
- ✅ GridSearch y comparación visual
- ✅ Selección de features (RFE)
- ❌ Código no reutilizable entre experimentos
- ❌ Configuración hardcodeada
- ❌ Sin gestión automática de artefactos
- ❌ Difícil de integrar en CI/CD

### 🔧 **Código del MLOps Engineer (Script)**

- ✅ **Configurable**: Todo parametrizado via YAML
- ✅ **Reproducible**: Mismo holdout (`split`) que feature engineering y que el notebook
- ✅ **Traceable**: Logging completo con MLflow, con **firma del modelo** inferida de datos reales
- ✅ **Automatizable**: CLI para integración CI/CD
- ✅ **Versionado**: Model Registry
- ✅ **Auditoría**: Métricas y metadatos registrados

## 📋 **Flujo de Configuración YAML**

### **`configs/model_config.yaml`** (generado por la última celda del notebook)

```yaml
model:
  name: house_price_model
  best_model: RandomForest          # ganador por mayor R² en test
  parameters:                       # get_params() completo del best_estimator_
    n_estimators: 50
    max_depth: null
    min_samples_split: 2
    min_samples_leaf: 1
    # ... resto de parámetros por defecto de sklearn
  r2_score: 0.9691                  # métrica de referencia
  mae: 21252.29
  target_variable: price
  feature_sets:
    rfe:                            # las 10 features elegidas por RFE (celda 3)
      - num__sqft
      - num__bedrooms
      - num__bathrooms
      - num__house_age
      - num__bed_bath_ratio
      - cat__location_Downtown
      - cat__location_Rural
      - cat__location_Suburb
      - cat__location_Waterfront
      - cat__condition_Good
    rfe_method: RandomForestRegressor
    selected_features_count: 10
    total_features: 15
  quality_gate:                     # umbrales que el script debe exigir en el holdout (reto lab 13.2)
    min_r2: 0.90
    max_mape: 0.10
    must_beat_baseline: true
```

> ⚠️ **Punto de decisión para el equipo.** El notebook compara modelos con las **10 features de RFE**, pero `train_model.py` entrena con las **15 columnas** (`Using 15 features` en el log). Las métricas son parecidas porque RandomForest ignora solo las features sin señal, pero no es lo mismo. Opciones: (a) que el script filtre por `feature_sets.rfe`, o (b) documentar que producción usa todas. Lo importante es que **notebook, script y API usen el mismo conjunto**.

> ⚠️ Versiones anteriores de esta guía incluían `price_per_sqft` entre las features. Se quitó porque se calcula con el precio (fuga del target; ver la guía 2).

El `baseline MAE 138000` es el error de predecir siempre la mediana: el modelo lo mejora ~6×, por eso pasa `must_beat_baseline`.

**Cuando el gate falla** (por ejemplo con `min_r2: 0.99` en el YAML) el script no guarda nada, deja un run `quality_gate_failed` en MLflow y termina con **exit code 1**, que es lo que hace fallar el job de CI:

```
2026-11-06 19:49:49 - ERROR - ❌ Quality gate: R² 0.9684 < min_r2 0.99
2026-11-06 19:49:50 - ERROR - Model NOT saved or registered. Exiting with code 1.
```

Verás un `FutureWarning` sobre `transition_model_version_stage`: los *stages* están deprecados desde MLflow 2.9 y desaparecen en 3.x. Funciona en 2.22.1; el reemplazo moderno son los **aliases** (`client.set_registered_model_alias(name, "production", version)`).

### **2. Para usar el modelo entrenado en la API (`src/api/inference.py`):**

El modelo y el preprocessor se cargan **una sola vez** al importar el módulo (no en cada request), y la predicción repite exactamente las mismas features derivadas que `engineer.create_features` (`house_age`, `bed_bath_ratio`). Si la API calcula una feature distinta a la del entrenamiento, el modelo recibe otra cosa de la que aprendió: **training/serving skew**.

Archivo completo (`main.py` importa `predict_price` **y** `batch_predict`; si falta alguno, uvicorn falla con `ImportError`):

```python
import joblib
import pandas as pd
import os
from datetime import datetime
from pathlib import Path
from .schemas import HousePredictionRequest, PredictionResponse

MODEL_PATH = "models/trained/house_price_model.pkl"
PREPROCESSOR_PATH = "models/trained/preprocessor.pkl"

try:
    print(f"🔍 Looking for model at: {MODEL_PATH}")
    print(f"🔍 Current working directory: {os.getcwd()}")
    print(f"🔍 Files in current directory: {os.listdir('.')}")
    
    # Verificar si el directorio models existe
    if os.path.exists("models/trained"):
        print(f"✅ models/trained directory exists")
        print(f"📁 Files in models/trained: {os.listdir('models/trained')}")
    else:
        print("❌ models/trained directory does not exist")
    
    model = joblib.load(MODEL_PATH)
    preprocessor = joblib.load(PREPROCESSOR_PATH)
    print(f"✅ Model loaded: {type(model).__name__}")
    print(f"✅ Preprocessor loaded successfully")
except Exception as e:
    print(f"❌ Error loading model or preprocessor: {str(e)}")
    raise RuntimeError(f"Error loading model or preprocessor: {str(e)}")

def predict_price(request: HousePredictionRequest) -> PredictionResponse:
    """
    Predict house price based on input features.
    """
    try:
        # ✅ PASO 1: Crear DataFrame con TODOS los datos
        input_data = pd.DataFrame([{
            'sqft': request.sqft,
            'bedrooms': request.bedrooms,
            'bathrooms': request.bathrooms,
            'location': request.location,
            'year_built': request.year_built,
            'condition': request.condition
        }])
        
        # ✅ PASO 2: Calcular features derivadas
        current_year = datetime.now().year
        input_data['house_age'] = current_year - input_data['year_built']
        input_data['bed_bath_ratio'] = input_data['bedrooms'] / input_data['bathrooms']
        
        # ✅ PASO 3: Aplicar preprocessing
        processed_features = preprocessor.transform(input_data)
        
        # ✅ PASO 4: Hacer predicción
        predicted_price = model.predict(processed_features)[0]
        
        # Convert to Python float, clamp to non-negative, and round
        predicted_price = max(0.0, float(predicted_price))
        predicted_price = round(predicted_price, 2)

        # Confidence interval (10% range), clamped to non-negative
        confidence_interval = [
            round(max(0.0, predicted_price * 0.9), 2),
            round(predicted_price * 1.1, 2)
        ]
        
        return PredictionResponse(
            predicted_price=predicted_price,
            confidence_interval=confidence_interval,
            features_importance={},
            prediction_time=datetime.now().isoformat()
        )
        
    except Exception as e:
        print(f"Error details: {str(e)}")
        raise Exception(f"Prediction failed: {str(e)}")

def batch_predict(requests: list[HousePredictionRequest]) -> list[PredictionResponse]:
    """
    Perform batch predictions.
    """
    return [predict_price(req) for req in requests]
```

Nunca re-partir con `train_test_split`. |
