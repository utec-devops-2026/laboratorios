Contexto del problema

El equipo
Equipo de IA de Netflix

Los compañeros de producto han lanzado una nueva función: los usuarios pueden escribir comentarios sobre las películas que ven.

El objetivo
Clasificador de sentimiento

Saber si el comentario es positivo → recomendar películas similares, o negativo → dejar de recomendar ese tipo de película.

🎯 Enfoque del taller: No nos importa el modelo en sí ni optimizarlo al máximo. Lo importante es entender el proceso MLOps completo: recolección de datos → entrenamiento → despliegue → inferencia. El modelo (XGBoost) se trata como caja negra.

Dataset: IMDB

En lugar de contratar personas que etiqueten comentarios, se usa el dataset público de IMDB. Cada reseña ya tiene puntuación, lo que permite enlazar texto con sentimiento positivo/negativo de forma automática.

25,000
reseñas de entrenamiento
20,000
palabras en el vocabulario
500
tokens por reseña (maxlen)

Las reseñas vienen pre-procesadas: cada palabra se convierte en un entero (su índice en el vocabulario). Las reseñas más cortas se rellenan con ceros (padding); las más largas se truncan. Resultado: una matriz de forma (25000, 500) lista para XGBoost.

from sagemaker.predictor import Predictor from sagemaker.serializers import CSVSerializer import json, urllib.request, numpy as np # cargar word_index with open("imdb_word_index.json") as f: word_index = json.load(f) # convertir texto a índices def texto_a_vector(texto, maxlen=500): tokens = texto.lower().split() indices = [word_index.get(w, 2) + 3 for w in tokens] indices = indices[-maxlen:] # truncar padded = [0] * (maxlen - len(indices)) + indices # padding return padded # tu reseña aquí resena = "This movie was absolutely fantastic the acting was superb" vector = texto_a_vector(resena) # invocar endpoint predictor = Predictor( endpoint_name="mi-primer-endpoint-serverless", serializer=CSVSerializer() ) csv_input = ",".join([str(x) for x in vector]) resultado = predictor.predict(csv_input).decode("utf-8").strip() print(f"Reseña: {resena}") print(f"Predicción: {'POSITIVA ✓' if float(resultado) > 0.5 else 'NEGATIVA ✗'}") print(f"Score: {float(resultado):.3f}")

[ 1 ] Importaciones y función de padding Setup
Carga librerías y define pad_sequences: rellena con ceros todas las secuencias hasta una longitud máxima (maxlen=500). Las secuencias más largas se truncan por la izquierda (se conserva el final, que suele ser más informativo).
joblib ↔

Como preparar el ColumnTransformer antes de hacer fit_transform. Defines la transformación antes de aplicarla.

import numpy as np def pad_sequences(sequences, maxlen, value=0): result = np.full((len(sequences), maxlen), value, dtype=np.int32) for i, seq in enumerate(sequences): if len(seq) > maxlen: seq = seq[len(seq) - maxlen:] result[i, maxlen - len(seq):] = seq return result

Flujo actual vs flujo ideal con SageMaker completo

Todas las cuentas AWS (nuevas, Academy, personales) parten con cuota 0 en instancias de training. En Academy no se puede aumentar. En cuentas personales o empresariales se solicita el aumento en Service Quotas y AWS lo aprueba en 1-3 días. Una vez habilitada, SageMaker delega el training a una instancia dedicada y el notebook solo orquesta — no computa.

Flujo ideal — con cuota habilitada (cuenta personal o empresarial tras solicitar aumento)
